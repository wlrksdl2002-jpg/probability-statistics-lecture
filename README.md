# 확률과 통계 강의자료 (공과대학 1학년, 10주)

주차별 강의 내용을 데이터로 작성하고, 스크립트로 애니메이션이 들어간 PowerPoint 한 파일을 만드는 프로젝트.

## 폴더
- `CLAUDE.md`: 강의 규칙 (대상, 말투, 구성)
- `00_기준/`: 스타일 가이드
- `02_초안/`: 10주 강의계획, 1주차 초안
- `04_제작도구/`: PPT 생성기 (`build.js`), 주차별 내용 (`content/`), 그래프 스크립트 (`figs/`)
- `05_이미지/`: 그래프 이미지, 위키미디어 공용 이미지와 출처 (`인터넷/credits/`)

교과서 원본(`01_원자료/`)과 완성된 PPT(`03_완성본/`)는 저장소에 포함하지 않음.

## PPT 만들기
```bash
cd 04_제작도구
npm install
node build.js        # → 03_완성본/확률과통계_1-10주차.pptx
node build.js 1 3    # 1·3주차만 미리보기
```
그래프 다시 그리기: `pip install matplotlib` 후 `python figs/figs_week01.py` 등 실행.

## 이미지 출처
`05_이미지/인터넷/` 의 사진은 위키미디어 공용의 자유 라이선스 이미지이며, 작가와 라이선스는 `credits/` 와 PPT 마지막 슬라이드에 표기.
