## 도입 (약 8분)

**1. 표지**

- 그림: 원형으로 배치된 6개 센서 일러스트

**2. 10주 강의 흐름**
- 경우의 수 → 확률 → 통계의 3단계 구성
- 그림: 10주 로드맵 (3개 구간 색 구분)

**3. 왜 경우의 수인가**
- 확률 = (원하는 경우의 수) / (전체 경우의 수)
- 경우의 수 계산이 확률 계산의 출발점
- 공학 사례: 비밀번호 보안 강도, 테스트 조합 수, 회로 배선 경우
- 그림: "경우의 수 → 확률 → 통계" 연결 화살표

**4. 학습목표**

## 복습 (약 7분)

**5. 합의 법칙과 곱의 법칙**
- 합의 법칙: 동시에 일어나지 않는 두 사건 → 경우의 수의 합
- 곱의 법칙: 잇달아 일어나는 두 사건 → 경우의 수의 곱
- 그림: 곱의 법칙 트리 다이어그램 (2가지 × 3가지 = 6가지)

**6. 순열과 계승(!)**
- 순열 nPr: 서로 다른 n개에서 r개를 택해 일렬로 배열하는 경우의 수
- nPr = n! / (n−r)!, 0! = 1
- 그림: 빈칸 r개에 n, n−1, n−2, … 가 차례로 들어가는 칸 그림

**7. 조합**
- 조합 nCr: 순서를 생각하지 않고 r개를 택하는 경우의 수
- nCr = n! / (r!(n−r)!)
- 그림: 순열 6개 → 조합 1개로 묶이는 그림 (ABC, ACB, … → {A,B,C})

## 원순열 (약 15분)

**8. 생각 열기: 바람개비** [교과서 p.11]
- 4가지 색 날개의 바람개비, 회전하면 같은 배열
- 그림: 같은 바람개비를 90°씩 돌린 4개 그림

**9. 일렬 배열 vs 원형 배열**
- 일렬: ABCD, BCDA, CDAB, DABC는 서로 다른 배열
- 원형: 네 배열 모두 회전하면 일치 → 같은 배열
- 그림: 왼쪽 일렬 4개 / 오른쪽 원탁 4개, 화살표로 회전 표시

**10. 원순열의 뜻**
- 원순열: 서로 다른 것을 원 모양으로 배열하는 순열
- 회전하여 일치하는 경우는 모두 같은 것으로 취급

**11. 원순열의 수 유도**
- 일렬 배열 n!가지 중 회전하여 같은 것이 n가지씩 존재
- 원순열의 수 = n! / n = (n−1)!
- 그림: 4! = 24개 배열이 6묶음(각 4개)으로 나뉘는 그림

**12. 다른 관점: 한 자리 고정**
- 한 사람 자리를 고정 → 나머지 (n−1)명의 일렬 배열
- 같은 결과 (n−1)!
- 그림: 원탁의 한 자리에 고정 핀 표시

**13. 예제 1: 원탁에 둘러앉기** [교과서 p.12 보기]
- 5명이 원탁에 둘러앉는 방법의 수: (5−1)! = 24
- 그림: 5인 원탁

**14. 예제 2: 이웃하여 앉기** [교과서 p.13 예제 1]
- 부모가 이웃하여 앉는 방법: 부모를 한 묶음으로 생각 → 원순열 × 묶음 안 자리바꿈 2!
- 그림: 부모를 하나의 덩어리로 묶은 원탁 그림

**15. 공학 예제: 원형 센서 배치** [공학]
- 서로 다른 센서 6개를 원형 측정 장치 둘레에 배치하는 방법의 수: (6−1)! = 120
- 장치가 회전 대칭이므로 회전하여 같은 배치는 같은 배치로 취급
- 그림: 원형 장치 위 센서 6개 배치도

## 중복순열 (약 12분)

**16. 생각 열기: OTP 비밀번호** [교과서 p.14]
- 0~9 숫자 중 중복을 허용하여 만드는 6자리 비밀번호
- 그림: OTP 생성기 화면

**17. 중복순열의 뜻과 수**
- 중복순열: 서로 다른 n개에서 중복을 허용하여 r개를 택하는 순열, 기호 nΠr
- 각 자리마다 n가지 선택 → 곱의 법칙으로 nΠr = n^r
- r > n 도 가능 (중복 허용 때문)
- 그림: r개의 빈칸 각각 아래에 "n가지" 표시

**18. 예제 3: 편지와 우체통** [교과서 p.15 예제 2]
- 서로 다른 편지 5통을 우체통 2개에 넣는 방법: 2Π5 = 2^5 = 32
- 주의: "편지가 우체통을 고르는 것" → 밑은 우체통 수 2, 지수는 편지 수 5
- 그림: 편지 5통에서 우체통 A/B로 향하는 화살표

**19. 공학 예제: 이진 코드와 작업 할당** [공학]
- n비트 이진 코드의 개수: 2^n (8비트 → 256가지)
- 서로 다른 작업 5개를 서버 3대에 할당하는 방법: 3^5 = 243
- 그림: 비트 수에 따른 2^n 증가 그래프 (n = 1~16, 막대그래프)

**20. 비밀번호 길이와 보안 강도** [공학]
- 숫자 4자리: 10^4 = 1만 가지 / 숫자 6자리: 10^6 = 100만 가지
- 영문 소문자+숫자 8자리: 36^8 ≈ 2.8조 가지
- 그림: 비밀번호 종류별 경우의 수 비교 막대그래프 (로그 눈금)
