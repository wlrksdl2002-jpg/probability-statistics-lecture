확률분포

6주차
확률분포(probability distribution)

확률변수의 각 값과 그 값을 가질 확률 사이의 대응 관계

P(X = xi) = pi (i = 1, 2, …, n)

0 ≤ pi ≤ 1, p1 + p2 + … + pn = 1

꺼낸 부품 중 불량품 개수

6주차
공학 예제
불량품 3개가 섞인 부품 10개에서 2개를 동시에 꺼낼 때, 불량품 개수 X의 확률분포
  1. P(X = 0) = 7C2 / 10C2 = 21/45
  2. P(X = 1) = 3C1 × 7C1 / 10C2 = 21/45
  3. P(X = 2) = 3C2 / 10C2 = 3/45
답 확률의 합 = 45/45 = 1 확인

기댓값

분포의 중심

비유

기댓값 = 분포의 무게중심

  • 확률을 무게로 보면 시소가 균형을 이루는 받침점의 위치
  • 자주 나오는 값 쪽으로 받침점이 이동
  • 기댓값: 오래 반복했을 때 평균적으로 기대되는 값

기댓값(평균)

6주차
기댓값(expected value)

확률변수의 각 값에 그 확률을 곱해 모두 더한 값. 평균이라고도 부름

E(X) = x1p1 + x2p2 + … + xnpn

기호 m 또는 μ로도 표시

기댓값은 '장기적 평균'

6주차
  • 주사위 눈 X의 기댓값: (1 + 2 + … + 6)/6 = 3.5
  • 3.5라는 눈은 실제로 나올 수 없는 값
  • 여러 번 반복할수록 평균이 가까워지는 값
  • → 한 번의 예측값이 아니라 장기적 평균

분산과 표준편차

6주차
분산(variance)과 표준편차(standard deviation)

확률변수의 값이 평균 m에서 흩어진 정도

V(X) = E((X − m)2) = E(X2) − {E(X)}2

표준편차 σ(X) = √V(X): 원래 단위로 되돌린 값

기계 A기계 B
평균1010
분산0.22
표준편차약 0.45약 1.41

고장 건수의 분산

6주차
공학 예제
앞의 하루 고장 건수 X (E(X) = 0.75)의 분산과 표준편차
  1. E(X2) = 0×0.5 + 1×0.3 + 4×0.15 + 9×0.05 = 1.35
  2. V(X) = 1.35 − 0.752 = 1.35 − 0.5625
  3. σ(X) = √0.7875
답 V(X) = 0.7875, σ(X) ≈ 0.887
