(a + b)3의 계수 = 조합의 수

3주차

  • a3−rbr의 계수 = 3Cr
  • (a + b)3 = 3C0a3 + 3C1a2b + 3C2ab2 + 3C3b3

이항정리

3주차
이항정리와 이항계수

n이 자연수일 때 (a + b)n의 전개식. 각 항의 계수 nCr는 이항계수

(a + b)n = nC0an + nC1an−1b + … + nCnbn

일반항: nCr an−r br (r = 0, 1, …, n)

이항계수의 성질

x에 1과 −1을 대입

이항계수의 합 = 2n

3주차
  • (1 + x)n = nC0 + nC1x + … + nCnxn
  • x = 1 대입 → nC0 + nC1 + … + nCn = 2n
  • n이 커질수록 가운데가 높은 종 모양
  • 가운데 계수(주황)가 가장 큼

x = 1 대입 vs x = −1 대입

3주차

x = 1

  • (1 + 1)n = 2n
  • nC0 + nC1 + … + nCn = 2n
  • n = 10 → 합 1024
  • 원소 n개 집합의 부분집합 수와 같은 값

x = −1

  • (1 − 1)n = 0
  • nC0 − nC1 + nC2 − … = 0
  • 짝수 번째 합 = 홀수 번째 합
  • 각각 2n−1

8비트에서 1의 개수별 비트열 수

3주차

모두 더하면 28 = 256 → 이항계수의 합이 전체 경우의 수

파스칼의 삼각형

3주차

n번째 줄 = (a + b)n의 이항계수. 13세기 양휘, 18세기 조선 홍정하도 같은 배열 사용

파스칼의 삼각형의 규칙

3주차
이웃한 두 수의 합

각 수는 바로 위 줄의 왼쪽 위 수와 오른쪽 위 수의 합

nCr = n−1Cr−1 + n−1Cr

특정 원소 하나를 포함하는 조합 + 포함하지 않는 조합

5C2 = 4C1 + 4C2 = 4 + 6 = 10
5번째 줄 10 = 바로 위 4 + 6

교과서 예제
파스칼의 삼각형을 이용하여 (a + b)6을 전개

골턴 보드: 못마다 왼쪽 또는 오른쪽

  • 공이 못을 만날 때마다 왼쪽(a) 또는 오른쪽(b)으로 이동
  • 오른쪽으로 k번 튀는 경로의 수 = nCk
  • 아래 칸에 쌓인 공의 모양 = 이항계수의 모양
