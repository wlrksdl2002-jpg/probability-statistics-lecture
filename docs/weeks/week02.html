2주차

같은 색 공끼리는 구별 불가 → 서로 다른 배열은 10가지뿐

왜 5!이 아니라 10가지인가

2주차
  • 공에 번호를 붙이면 서로 다른 공 5개의 배열: 5! = 120
  • 번호만 바꾼 배열은 같은 배열: 3! × 2! = 12가지씩 겹침
  • 구하는 수를 k라 하면 k × 3! × 2! = 5!
  • k = 5!/(3! × 2!) = 10

같은 것이 있는 순열의 수

2주차
같은 것이 있는 순열

n개 중 같은 것이 각각 p개, q개, …, r개씩 있을 때 n개를 모두 일렬로 배열하는 순열

n! / (p! × q! × … × r!)

단, p + q + … + r = n. 분모의 1!은 생략

상황계산결과
노란 공 3, 파란 공 25!/(3!2!)10
a, a, b, b, b5!/(2!3!)10
1, 1, 2, 2, 2, 3, 37!/(2!3!2!)210

비유

바둑판 도시의 최단 경로

  • 격자 도로에서 최단 경로 = 오른쪽(→)과 위쪽(↑)만으로 이동
  • 경로 하나 = →와 ↑를 일렬로 늘어놓은 문자열
  • 최단 경로의 수 = 같은 것이 있는 순열의 수

학교에서 집까지 최단 경로

2주차
교과서 예제
오른쪽 4칸, 위쪽 3칸 떨어진 집까지 도로망을 따라 최단 거리로 가는 방법의 수
  1. 오른쪽 한 칸 = a, 위쪽 한 칸 = b로 표시
  2. 최단 경로 = a 4개, b 3개의 일렬 배열
  3. 예: a a b a b b a
답 7!/(4! × 3!) = 35

P 지점을 거쳐 가는 최단 경로

2주차
교과서 예제
A에서 출발하여 P를 거쳐 B까지 최단 거리로 가는 방법의 수 (A→P: →2, ↑2 / P→B: →3, ↑2)
  1. A → P: 4!/(2! × 2!) = 6
  2. P → B: 5!/(3! × 2!) = 10
  3. 두 구간은 잇달아 일어남 → 곱의 법칙
답 6 × 10 = 60

중복조합의 수

2주차
중복조합 nHr

서로 다른 n개에서 중복을 허용하여 r개를 택하는 조합 (H: homogeneous)

nHr = n+r−1Cr

공(○) r개와 칸막이(|) n−1개의 배열 수와 같은 값. r > n도 가능

중복순열 vs 중복조합

2주차

중복순열 nΠr = nr

  • 순서 구분 O
  • 예: 3종 문자로 4자리 코드
  • 3Π4 = 34 = 81
  • 자리마다 n가지 선택

중복조합 nHr = n+r−1Cr

  • 순서 구분 X
  • 예: 3종 부품 4개 주문
  • 3H4 = 6C4 = 15
  • 종류별 개수만 결정

방정식의 정수해 개수

2주차
교과서 예제
x + y + z = 7을 만족시키는 (1) 음이 아닌 정수해 (2) 양의 정수해의 개수
  1. (1) x, y, z 중 중복 허용하여 7개 택하기: 3H7 = 9C7 = 36
  2. (2) x = a+1, y = b+1, z = c+1로 놓으면 a + b + c = 4
  3. a, b, c는 음이 아닌 정수 → 3H4 = 6C4 = 15
답 (1) 36 (2) 15

서버 3대에 요청 나누기

2주차
공학 예제
구별되지 않는 요청 10건을 서버 3대에 나눌 때, 각 서버가 최소 2건씩 처리하는 방법의 수
  1. 서버별 요청 수 x + y + z = 10 (x, y, z ≥ 2)
  2. 각 서버에 2건씩 먼저 배정 → 남은 4건 분배
  3. a + b + c = 4의 음이 아닌 정수해 → 3H4
  4. 참고: 제한 없으면 3H10 = 12C10 = 66

탐구: 소화기 배치

2주차
교과서 예제
일렬로 놓인 객실 10개 중 3곳의 문 앞에 소화기를 놓되, 어느 두 소화기도 이웃하지 않게 놓는 방법의 수
  1. 소화기 3대로 나뉜 네 구역 A, B, C, D의 객실 수: a + b + c + d = 7
  2. 이웃 금지 → 가운데 구역 b ≥ 1, c ≥ 1
  3. b, c에 1개씩 먼저 배정 → a + b′ + c′ + d = 5
답 4H5 = 8C5 = 56
