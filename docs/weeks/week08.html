이산확률변수

  • 하나하나 셀 수 있는 값
  • 예: 하루 고장 건수, 불량품 개수

연속확률변수

  • 어떤 구간의 모든 실수 값
  • 예: 저항값, 부품 수명, 측정 오차
  • 확률 = 곡선 아래의 넓이

확률밀도함수

8주차
확률밀도함수 f(x)

연속확률변수 X의 확률을 그래프 아래의 넓이로 나타내는 함수

P(a ≤ X ≤ b) = 색칠한 부분의 넓이

조건: f(x) ≥ 0, 그래프와 x축 사이 전체 넓이 = 1

연속확률변수의 성질

8주차
  • 모든 x에서 f(x) ≥ 0
  • 곡선과 x축 사이 전체 넓이 = 1
  • 한 점에서의 확률 P(X = a) = 0
  • P(a ≤ X ≤ b) = P(a < X < b): 등호 유무와 무관
P(X = a) = 0
폭이 0인 선분의 넓이 = 0

균등한 대기 시간

8주차
공학 예제
서버 응답 대기 시간 X(분)의 확률밀도함수 f(x) = 1/10 (0 ≤ x ≤ 10). P(2 ≤ X ≤ 5)?
  1. 구하는 확률 = 직사각형의 넓이
  2. 가로: 5 − 2 = 3, 세로: 1/10
  3. 넓이 = 3 × 1/10
답 P(2 ≤ X ≤ 5) = 0.3

정규분포

자연과 공학에서 가장 자주 만나는 분포

비유

과녁의 화살: 가운데로 모이는 오차

  • 중심 근처의 화살 다수, 크게 벗어난 화살 소수
  • 측정 오차도 같은 모양: 작은 오차 다수, 큰 오차 소수
  • 이 모양을 나타내는 분포가 정규분포

정규분포

8주차
정규분포 N(m, σ2)

평균 m, 표준편차 σ인 종 모양의 연속확률분포

f(x) = 1/(√(2π) σ) × e−(x−m)2/(2σ2)

핵심: 공식 암기보다 그래프 모양과 m, σ의 역할

정규분포 곡선의 성질

8주차
  • 직선 x = m에 대하여 대칭
  • x = m에서 최댓값
  • m이 커지면 곡선이 오른쪽으로 평행이동
  • σ가 커지면 낮고 넓게 퍼진 모양

표준화

평균을 빼고 표준편차로 나누어 N(0, 1)로 바꾸는 과정

Z = (X − m)/σ

X ~ N(m, σ2) 이면 Z ~ N(0, 1): 표준정규분포

표준정규분포표 읽기

8주차
  • 표의 값: P(0 ≤ Z ≤ z), 0부터 z까지의 넓이
  • 대칭 이용: P(−z ≤ Z ≤ 0) = P(0 ≤ Z ≤ z)
  • 오른쪽 꼬리: P(Z ≥ z) = 0.5 − P(0 ≤ Z ≤ z)

저항값의 합격 비율

8주차
공학 예제
저항값 X ~ N(100, 22) (단위 Ω). 98 ≤ X ≤ 104인 저항의 비율?
  1. 표준화: Z = (X − 100)/2
  2. 98 → Z = −1, 104 → Z = 2
  3. P(−1 ≤ Z ≤ 2) = P(0 ≤ Z ≤ 1) + P(0 ≤ Z ≤ 2)
  4. = 0.3413 + 0.4772
답 0.8185, 약 81.9%

측정 오차가 클 확률

8주차
공학 예제
길이 측정 오차 X ~ N(0, 0.52) (단위 mm). 오차의 크기가 1mm를 넘을 확률?
  1. |X| > 1: X < −1 또는 X > 1
  2. 표준화: ±1 → Z = ±1/0.5 = ±2
  3. P(|Z| > 2) = 2 × (0.5 − 0.4772)
답 0.0456, 약 4.6%
