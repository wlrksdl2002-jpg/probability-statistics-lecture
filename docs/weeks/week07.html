이항분포의 정의

7주차
이항분포(binomial distribution)

한 번의 시행에서 사건 A가 일어날 확률이 p일 때, n번의 독립시행에서 A가 일어나는 횟수 X의 확률분포

P(X = r) = nCr pr qn−r (r = 0, 1, …, n)

기호 B(n, p)로 표시, q = 1 − p

'이항'이라는 이름의 유래

7주차
  • (q + p)n을 이항정리로 전개한 각 항 = 각 확률
  • nC0qn + nC1pqn−1 + … + nCnpn
  • (q + p)n = 1n = 1 → 확률의 합이 1
  • 3주차 이항정리·파스칼의 삼각형과 연결

이항분포의 확률 계산

샘플링 검사에 적용

표본 10개 중 불량품 개수

7주차
공학 예제
불량률 10%인 생산 라인에서 부품 10개를 임의로 뽑을 때, 불량품 개수 X가 1개 이하일 확률
  1. X ~ B(10, 0.1)
  2. P(X = 0) = 0.910 ≈ 0.349
  3. P(X = 1) = 10C1 × 0.1 × 0.99 ≈ 0.387
답 P(X ≤ 1) ≈ 0.736

실제로 1000번 검사해 보면

7주차

컴퓨터 시뮬레이션 1000회의 상대도수 ≈ 이론값 B(10, 0.1)

계산 도구 활용

7주차
  • 엑셀: =BINOM.DIST(1, 10, 0.1, FALSE) → 0.387
  • 누적 P(X ≤ 1): =BINOM.DIST(1, 10, 0.1, TRUE) → 0.736
  • 파이썬: scipy.stats.binom.pmf(1, 10, 0.1) → 0.387
  • n이 크면 손 계산 대신 도구 사용
구하는 값엑셀 함수
P(X = r)BINOM.DIST(r, n, p, FALSE)
P(X ≤ r)BINOM.DIST(r, n, p, TRUE)

이항분포의 평균과 분산

7주차
B(n, p)의 평균·분산

복잡한 합 계산 없이 n과 p만으로 바로 계산

E(X) = np, V(X) = npq, σ(X) = √(npq)

예: B(10, 0.1) → 평균 1, 분산 0.9, 표준편차 ≈ 0.949

분포평균 np분산 npq
B(4, 0.5)21
B(10, 0.1)10.9
B(100, 0.01)10.99

평균과 분산의 직관

7주차
  • 평균 np: 성공률 30%로 100번 → 약 30번 성공
  • 분산 npq: p = 0.5일 때 최대 (결과 예측이 가장 어려움)
  • p가 0 또는 1에 가까우면 분산 작음 (결과가 거의 정해짐)

100비트 패킷의 오류

7주차
공학 예제
비트 오류율 0.01인 채널로 100비트 패킷 전송. 오류 비트 수 X의 평균과, 오류가 하나 이상 있을 확률 (각 비트는 독립)
  1. X ~ B(100, 0.01)
  2. E(X) = 100 × 0.01 = 1
  3. P(X = 0) = 0.99100 ≈ 0.366
답 P(X ≥ 1) = 1 − 0.366 ≈ 0.634

샘플링 검사의 합격 판정

7주차
공학 예제
로트에서 부품 20개를 뽑아 불량품이 1개 이하이면 로트 합격. 로트의 불량률 p에 따른 합격 확률
  1. X ~ B(20, p), 합격 = P(X ≤ 1)
  2. P(X ≤ 1) = q20 + 20pq19
  3. p = 0.05 → 0.736, p = 0.1 → 0.392
답 불량률이 높을수록 합격 확률 급감
