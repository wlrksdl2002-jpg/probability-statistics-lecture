점추정과 구간추정

10주차

점추정

  • 모평균을 값 하나로 추정
  • 예: 배터리 평균 수명 500시간
  • 간단하지만 정확도 정보 부재

구간추정

  • 모평균이 들어 있을 범위로 추정
  • 예: 496.08 ~ 503.92시간
  • 정확도(신뢰도)를 함께 표현
비유

작살과 그물

  • 점추정 = 작살: 한 점을 정확히 맞히기 어려운 방식
  • 구간추정 = 그물: 범위를 던져 잡을 가능성 증가
  • 넓은 그물(높은 신뢰도)일수록 잘 잡지만 위치는 덜 정밀

신뢰구간

표본평균의 분포에서 출발

신뢰구간의 유도

10주차
  • X̄ ~ N(m, σ2/n) → Z = (X̄ − m)/(σ/√n) ~ N(0, 1)
  • P(−1.96 ≤ Z ≤ 1.96) = 0.95
  • 괄호 안 부등식을 m에 대하여 정리
  • X̄ − 1.96 σ/√n ≤ m ≤ X̄ + 1.96 σ/√n

모평균의 신뢰구간

10주차
모평균 m의 신뢰구간

모표준편차 σ인 모집단에서 크기 n인 표본의 표본평균 x̄ 이용

x̄ − 1.96 σ/√n ≤ m ≤ x̄ + 1.96 σ/√n

신뢰도 95% 기준. 신뢰도 99%는 1.96 대신 2.58

신뢰도z 값의미
95%1.96P(|Z| ≤ 1.96) = 0.95
99%2.58P(|Z| ≤ 2.58) = 0.99

배터리 수명: 신뢰도 95%

10주차
공학 예제
배터리 100개의 수명 표본평균 500시간, 모표준편차 20시간. 모평균 m의 신뢰도 95% 신뢰구간?
  1. σ/√n = 20/√100 = 2
  2. 1.96 × 2 = 3.92
  3. 500 − 3.92 ≤ m ≤ 500 + 3.92
답 496.08 ≤ m ≤ 503.92 (시간)
x̄ ± 1.96 × σ/√n
= 500 ± 3.92

배터리 수명: 신뢰도 99%

10주차
공학 예제
같은 자료(n = 100, x̄ = 500, σ = 20)로 신뢰도 99% 신뢰구간?
  1. σ/√n = 2
  2. 2.58 × 2 = 5.16
  3. 500 − 5.16 ≤ m ≤ 500 + 5.16
답 494.84 ≤ m ≤ 505.16 (시간)

신뢰구간 100개 시뮬레이션

10주차

표본을 100번 뽑아 만든 95% 신뢰구간: 청록 = m 포함(98개), 주황 = m 미포함(2개)

신뢰도 95%의 올바른 해석

10주차
  • 같은 방법으로 신뢰구간을 100개 만들면 약 95개가 m을 포함
  • m은 고정된 값, 표본마다 달라지는 것은 구간
  • 구간 하나의 m 포함 여부: 판단 불가
약 95개 / 100개
모평균 m을 포함하는 구간의 비율
