시행, 표본공간, 사건

4주차

  • 사건: 표본공간의 부분집합
  • 동전 3개 던지기 → n(S) = 23 = 8

수학적 확률

4주차
수학적 확률

각 결과가 일어날 가능성이 같은 표본공간 S에서 사건 A가 일어날 확률

P(A) = n(A) / n(S)

예: 주사위 2개의 합이 7 → 6/36 = 1/6

불량품을 꺼낼 확률

4주차
공학 예제
제품 10개 중 불량품이 3개. 임의로 2개를 꺼낼 때 2개 모두 불량품일 확률
  1. 전체: 10개 중 2개 택하기 → 10C2 = 45
  2. 사건: 불량품 3개 중 2개 택하기 → 3C2 = 3
  3. 경우의 수로 확률 계산 → 1~3주차 내용 활용
답 3/45 = 1/15

동전 한 번은 예측 불가, 만 번은 예측 가능

  • 한 번 던진 결과: 앞뒤 예측 불가
  • 여러 번 반복: 앞면 비율이 일정한 값에 가까워짐
  • 확률 = 반복할 때 드러나는 규칙성

통계적 확률과 큰수의 법칙

4주차
통계적 확률

같은 시행을 n번 반복할 때 사건 A가 rn번 일어나면, n이 충분히 클 때 상대도수 rn/n이 가까워지는 일정한 값

rn / n → P(A)

예: 부품 2000개 검사, 불량 36개 → 불량률 약 0.018

수학적 확률 vs 통계적 확률

4주차

수학적 확률

  • 근거: 경우의 수 계산
  • 조건: 각 결과가 일어날 가능성이 모두 동일
  • 예: 주사위 눈 1이 나올 확률 1/6
  • 실험 없이 계산 가능

통계적 확률

  • 근거: 반복 실험의 상대도수
  • 조건: 충분히 많은 반복
  • 예: 공정 불량률, 부품 고장률
  • 공학 현장에서 주로 사용

확률의 기본 성질

4주차
  • 임의의 사건 A에 대하여 0 ≤ P(A) ≤ 1
  • 반드시 일어나는 사건: P(S) = 1
  • 절대 일어나지 않는 사건: P(∅) = 0
  • 확률이 1보다 크거나 음수이면 계산 오류
0 ≤ P(A) ≤ 1
P(∅) = 0, P(S) = 1

확률의 덧셈정리

합사건의 확률

합사건과 곱사건

4주차
  • 합사건 A ∪ B: A 또는 B가 일어나는 사건
  • 곱사건 A ∩ B: A와 B가 동시에 일어나는 사건
  • 벤 다이어그램으로 영역 확인

확률의 덧셈정리

4주차
덧셈정리

두 사건 A, B에 대하여 A 또는 B가 일어날 확률

P(A ∪ B) = P(A) + P(B) − P(A ∩ B)

P(A) + P(B)에서 겹친 부분 A ∩ B가 두 번 더해짐 → 한 번 빼기

2의 배수 또는 3의 배수

4주차
교과서 예제
1부터 20까지 적힌 카드 20장 중 1장을 뽑을 때, 2의 배수 또는 3의 배수일 확률
  1. A: 2의 배수 → 10장, P(A) = 10/20
  2. B: 3의 배수 → 6장, P(B) = 6/20
  3. A ∩ B: 6의 배수 → 3장, P(A ∩ B) = 3/20
답 10/20 + 6/20 − 3/20 = 13/20
사건카드확률
A (2의 배수)2, 4, …, 2010/20
B (3의 배수)3, 6, …, 186/20
A ∩ B (6의 배수)6, 12, 183/20

부품 검사: 결함이 하나라도 있을 확률

4주차
공학 예제
외관 결함 확률 0.05, 전기적 결함 확률 0.03, 두 결함이 모두 있을 확률 0.01일 때 결함이 하나라도 있을 확률
  1. A: 외관 결함, B: 전기적 결함
  2. '하나라도' = A ∪ B
  3. 0.05 + 0.03 − 0.01
답 P(A ∪ B) = 0.07

배반사건

4주차
배반사건

A ∩ B = ∅, 즉 두 사건이 동시에 일어나지 않는 관계

P(A ∪ B) = P(A) + P(B)

예: 주사위 2개의 합이 3 또는 11 → 2/36 + 2/36 = 1/9

여사건의 확률

'적어도'는 반대로 생각

비유

비 올 확률 30%면 안 올 확률은?

  • 비가 온다 / 안 온다: 둘 중 하나는 반드시 일어남
  • P(비 안 옴) = 1 − 0.3 = 0.7
  • 직접 세기 어려우면 반대 사건을 세기

여사건의 확률

4주차
여사건 Ac

사건 A가 일어나지 않는 사건. A와 Ac는 서로 배반사건

P(Ac) = 1 − P(A)

'적어도 하나'의 확률 = 1 − '하나도 없음'의 확률

적어도 1개가 불량품일 확률

4주차
공학 예제
제품 10개 중 불량품 3개. 임의로 3개를 꺼낼 때 적어도 1개가 불량품일 확률
  1. 여사건: 3개 모두 정상품
  2. 정상품 7개 중 3개: 7C3 = 35, 전체 10C3 = 120
  3. P(모두 정상) = 35/120 = 7/24
답 1 − 7/24 = 17/24 (약 0.71)
P(A) = 1 − 7C3 / 10C3
직접 세면 불량 1개, 2개, 3개 세 경우 → 여사건이 간단
