9주차

전수조사

  • 모집단 전체를 조사
  • 정확하지만 큰 시간과 비용
  • 예: 인구 총조사

표본조사

  • 모집단의 일부만 조사
  • 빠르고 경제적
  • 예: 전구 수명 시험(파괴 검사)
  • 예: 반도체 웨이퍼 샘플 검사

임의추출

9주차
  • 임의추출: 모든 대상이 뽑힐 확률이 같도록 추출
  • 복원추출: 뽑은 것을 되돌려 놓고 다시 추출
  • 비복원추출: 되돌려 놓지 않고 추출
  • 생산 라인: 난수로 검사할 부품 번호 선택
임의추출 = 공정한 추첨
치우친 표본 → 잘못된 결론

표본평균의 평균과 분산

9주차
표본평균 X̄의 평균·분산

모평균 m, 모분산 σ2인 모집단에서 크기 n인 표본을 임의추출할 때

E(X̄) = m, V(X̄) = σ2/n, σ(X̄) = σ/√n

n이 커질수록 m 근처로 더 모이는 X̄

n이 커지면 X̄의 분포는 종 모양

9주차

주사위를 n개 던져 구한 눈의 평균, 20000번 시뮬레이션 (점선: 모평균 3.5)

비유

갈톤 보드: 작은 우연이 모여 종 모양

  • 못을 만날 때마다 왼쪽 또는 오른쪽으로 이동하는 구슬
  • 우연한 이동이 여러 번 더해진 결과 → 가운데에 가장 많은 구슬
  • 많은 값의 합과 평균은 정규분포에 가까워지는 성질

표본평균의 분포

9주차
표본평균의 분포

모집단이 정규분포면 X̄도 정규분포, 정규분포가 아니어도 n이 충분히 크면 근사적으로 정규분포

X̄ ~ N(m, σ2/n)

보통 n ≥ 30이면 충분히 큰 것으로 취급

부품 무게의 표본평균

9주차
공학 예제
부품 무게: 모평균 50g, 모표준편차 4g. 16개를 임의추출할 때 표본평균이 52g 이상일 확률?
  1. X̄ ~ N(50, 42/16) = N(50, 12)
  2. 표준화: Z = (52 − 50)/1 = 2
  3. P(X̄ ≥ 52) = P(Z ≥ 2) = 0.5 − 0.4772
답 0.0228, 약 2.3%

이항분포의 정규근사

n이 크면 이항분포도 종 모양

n이 커지면 이항분포는 정규분포 모양

9주차

B(n, 0.1): 불량률 10%인 부품 n개 중 불량품 개수 (곡선: 근사 정규분포)

이항분포의 정규근사

9주차
이항분포의 정규근사

n이 충분히 크면 이항분포 B(n, p)를 정규분포로 근사

B(n, p) ≈ N(np, npq), q = 1 − p

n이 충분히 큰 기준: 보통 np ≥ 5, nq ≥ 5

불량품 개수의 근사 확률

9주차
공학 예제
불량률 10%인 공정에서 부품 400개 검사. 불량품이 46개 이하일 확률?
  1. X ~ B(400, 0.1): 평균 400 × 0.1 = 40
  2. 분산 400 × 0.1 × 0.9 = 36, 표준편차 6
  3. X ≈ N(40, 62), Z = (46 − 40)/6 = 1
  4. P(Z ≤ 1) = 0.5 + 0.3413
답 0.8413, 약 84%
